# Life OS Sheets

Этот проект создаёт Google Sheets для управления различными аспектами жизни: финансами, учёбой, стратегией и wishlist'ом. Архитектура построена на классах для лёгкого расширения, включая будущую интеграцию с ботом.

## Структура проекта

- `src/life_os/`: Основной пакет.
  - `core/`: Основные классы (life_os.py, auth.py).
  - `sheets/`: Классы для создания вкладок (finances.py, study_tracker.py, strategy.py, wishlist.py, design.py).
- `scripts/create_life_os.py`: Скрипт для запуска создания таблиц.
- `README.md`: Документация.
- `pyproject.toml`: Конфигурация проекта.

## Установка

1. Убедитесь, что у вас установлен Python 3.12+ и uv.

2. Клонируйте репозиторий и перейдите в директорию проекта.

3. Установите зависимости:
   ```
   uv sync
   ```

## Настройка Google API

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).

2. Создайте новый проект или выберите существующий.

3. Включите Google Sheets API и Google Drive API.

4. Создайте credentials для OAuth 2.0:
   - Перейдите в "Credentials" > "Create Credentials" > "OAuth client ID".
   - Выберите "Desktop application".
   - Скачайте файл `credentials.json` и поместите его в корень проекта.

5. При первом запуске скрипт откроет браузер для авторизации и создаст `token.json`.

## Запуск

Запустите скрипт создания:
```
python scripts/create_life_os.py
```

Скрипт создаст новую Google Sheet с вкладками и применит форматирование.

## Архитектура для бота

Проект спроектирован с учётом будущей интеграции с ботом (например, Telegram bot). Класс LifeOS можно расширить методами для взаимодействия с ботом, а отдельные классы вкладок позволяют легко добавлять функции чтения/записи данных.

## Зависимости

- gspread: Для работы с Google Sheets.
- google-auth: Для аутентификации.

Установлены через uv в `pyproject.toml`.
